Falta un paso para abrir LightCraft

GitHub Pages está mostrando los archivos del repositorio en lugar del programa. LightCraft se tiene que compilar primero; eso lo hace GitHub Actions automáticamente. Sigue estos pasos una sola vez:

1Agregar el flujo de compilación (si ya existe .github/workflows/pages.yml en tu repositorio, salta al paso 2)

Al subir archivos desde un Mac, la carpeta oculta .github suele quedar fuera. Este botón la crea por ti: se abre GitHub con el archivo listo; solo pulsa Commit changes… y luego Commit changes.

Crear el archivo (rama main) … si tu rama se llama master
2Elegir GitHub Actions como origen de Pages

En la página que se abre: Build and deployment ▸ Source ▸ elige GitHub Actions (en vez de "Deploy from a branch").

Abrir ajustes de Pages
3Compilar y publicar

En Actions, entra a Deploy to GitHub Pages ▸ Run workflow. La primera vez tarda entre 30 y 60 minutos. Cuando aparezca el visto verde, recarga esta dirección: se abrirá el programa.

Abrir Actions
